## Summary: Key Trends (2024-2026)

1. **RL + Realistic Environments**: Papers increasingly incorporate transaction costs, slippage, margin, anti-lookahead semantics (2604.00031, 2410.23294, 10.34726/hss.2025.121287)
2. **LLM + RL Fusion**: LLM as policy network (FLAG-Trader), LLM for s-CoT reasoning (Attractor-Aware), LLM for hierarchical decisions (Moira, META)
3. **Multi-Agent Systems**: A3C async workers per currency (2405.19982), specialized indicator agents (META), debate/coordination (FinCon, TradingGPT)
4. **Inference-Time Optimization**: Planning at deployment without retraining (2605.12653), prompt adaptation (Moira), episodic memory retrieval (META)
5. **Benchmarking & Evaluation**: Live benchmarks (AI-Trader), pre-registered tests (Soufi 2026), walk-forward with transaction costs (Lim 2026)
6. **FX-Specific Focus**: Most papers test on major pairs (EURUSD, USD/TWD, USD/CHF, 9-pair baskets); few on exotic/EM currencies
7. **Risk-Aware Objectives**: Lipschitz constraints, risk-aversion in reward, drawdown control, Sharpe optimization
